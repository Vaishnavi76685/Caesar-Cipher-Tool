# Caesar Cipher Encryption Tool

A simple web-based tool to encrypt and decrypt messages using the Caesar Cipher technique.

## Features
- Encrypt messages using a shift key.
- Decrypt encrypted messages.
- Supports uppercase and lowercase letters.
- Preserves numbers, spaces and special characters.
- Copy encrypted or decrypted results.
- Clear all input and output fields.
- Input validation for shift keys.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the live website.
2. Enter your message.
3. Enter a shift key between 1 and 25.
4. Click Encrypt or Decrypt.
5. Copy the result using the Copy Result button.
